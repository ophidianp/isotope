Three steps to an older (or newer) mod.

  1. Install Isotope. Put the Isotope jar in your normal mods folder, next to Fabric API if your other mods need it. Start the game once.
  2. Add mods for other versions. Put them in the new isotope/mods folder. Their own dependencies still need installing, ideally as builds for your version.
  3. Launch and read the report. Start the game, then open isotope/report.txt. Settings live in config/isotope.properties.

Tip: if Isotope guesses a mod's version wrong, put the jar in a folder named after its version, such as isotope/mods/26.1.2/.
