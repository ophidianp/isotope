Transparency

Made with Claude. Said plainly.

Isotope was made with Claude, Anthropic's AI, working through Claude Code. I chose what to build, tested it, and decide what ships. This page says which parts were whose, and how much of it is still unproven.

Who wrote it

The code came from AI

The mod, its table generator, its tests, this website and its copy were written by Claude in Claude Code, by Claude Fable 5.2 and Claude Opus 5.5.

What I did

One person steering

I asked for the mod, chose its name and direction, and decide what gets released. I publish each release myself.

Not proven

What is still unverified

Isotope has not been run on a client yet, only on a 26.3 dedicated server.

Checked and not checked

What has been tested, and what hasn't.

These are the claims I can stand behind today, and the ones I can't yet.

A · Checked

Builds and unit tests

Builds are made from a clean state. Fifteen unit tests cover the rewrite, the reference check, stubs, sealed classes and the startup analysis.

B · Checked

Real mods on a real server

Real 26.1.x mods were run through Isotope on a 26.3 server, which reaches "Done" with seven of them loaded. Crash predictions were confirmed by turning the safety check off. Each data-file rule is checked against all of Mojang's own files.

C · Untested

No client run yet

Rendering, screens and client-side mixins of rewritten mods are rewritten and checked, but have not been exercised in a real game client.

D · Limited

Backwards is less tested

Going from a newer mod to an older game was checked offline (Cloth Config for 26.3 against 26.2: 97 references redirected, 1 left over), not in a running game.

E · Fragile

Fabric Loader internals

Fabric has no public way to add mods after start-up, so Isotope uses its internals. A future Fabric Loader can break that; Isotope is written to switch itself off with a log line rather than crash.

Where it comes from

Built on other people's work.

Isotope is a separate project and is not affiliated with any of these.

A · Platform

Fabric Loader and ASM

Isotope runs inside Fabric Loader and uses the ASM bytecode library that ships with it. It has no other dependencies.

B · Source

Mojang's game jars

The rename tables were worked out by comparing Mojang's published game jars. The tables hold names only; no game code is included.

C · Credit

Prior art

Retromod and RetroMod (Bownlux) explored rewriting old mods for new versions first. Isotope's approach was designed separately and shares no code with them.
