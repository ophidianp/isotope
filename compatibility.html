Compatibility

Twelve real mods. Real results.

We took twelve Fabric mods from Modrinth whose newest build is for 26.1.x and put them through Isotope on a Minecraft 26.3 dedicated server. Here is exactly what happened.

With the safety check switched off, Carved Wood, Thermoo, Artifacts and YUNG's API all really did crash the server at startup. Frostiful was not crash-tested because it also needs YACL, which was not installed. "Loaded" means the server started; client-side features are untested.

Limits

What it cannot do.

Isotope is a compatibility layer, not a port. These are the walls it hits.

A

Redesigned systems

If a system was rebuilt, the old calls have no equivalent. World-generation mods crossing 26.2 → 26.3 will generally not work.

REDESIGN
B

Changed behaviour

A method that kept its name but now does something different looks fine to Isotope. Only playing shows it.

SILENT
C

Data files

Recipes, loot tables and world-gen JSON are not converted yet. The game may skip an old mod's data with errors in the log.

NOT YET
D

Older Minecraft

1.21.x and earlier are obfuscated and use a different toolchain. Out of scope.

OUT OF SCOPE
E

Clients, so far

Only tested on a dedicated server. Rendering, screens and client mixins of rewritten mods have not run in a real client yet.

UNTESTED

Other projects

Others in this space. Some may suit you better.
